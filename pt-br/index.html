Por que usar

Escreva uma vez, use em todo lugar

Os recursos ficam no núcleo; cada integração é uma camada fina. Uma correção ou um recurso novo chega a todos os sistemas.

🧠 Núcleo sem framework

Extensões, comandos declarativos, barra, balão, menus e diálogos em DOM puro, com TypeScript estrito.

🧩 Em qualquer página

Web component que participa de formulários como um textarea, ou arquivo único (UMD) para páginas sem bundler.

🗂️ Recursos de editor completo

Tabelas com legenda e rodapé, mídia com upload, menções, campos de mesclagem, fórmulas, sumário, localizar e substituir.

📝 Revisão e verificação

Comentários, sugestões com controle de alterações, versões, papéis e verificadores de acessibilidade, links e ortografia.

🌎 Feito para o Brasil

Interface em português do Brasil, inglês e espanhol, exemplos com o tema GOV.BR e documentação bilíngue.

✅ Testado e aberto

Centenas de testes (Vitest), CI em cada mudança e licença MIT.

Começo rápido

Escolha como usar

Os pacotes são distribuídos pelas releases do GitHub.

  1. HTML puro (Django, PHP...): carregue o arquivo kelsoncm-tiptap.bundle.js da release do web component e use <kelsoncm-tiptap name="campo"> no formulário.
  2. Com bundler: instale o tarball da release do @kelsoncm/tiptap-core e chame createEditorUI(elemento, opções).
  3. Angular: use o <app-editor> do tiptap-ng com formControlName ou ngModel.
  4. Moodle: instale o plugin editor_tiptap e escolha a barra, os recursos e os plugins na administração.

Passo a passo, opções e comandos nos primeiros passos.
