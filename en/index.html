Why use it

Write once, use everywhere

Features live in the core; each integration is a thin layer. A fix or a new feature reaches every system.

🧠 Framework-agnostic core

Extensions, declarative commands, toolbar, balloon, menus and dialogs in plain DOM, with strict TypeScript.

🧩 In any page

A web component that takes part in forms like a textarea, or a single file (UMD) for pages without a bundler.

🗂️ Full editor features

Tables with caption and footer, media with uploads, mentions, merge fields, equations, table of contents, find and replace.

📝 Review and checks

Comments, suggestions with change tracking, versions, roles, and accessibility, link and spelling checkers.

🌎 Made for Brazil

Interface in Brazilian Portuguese, English and Spanish, examples with the GOV.BR theme and bilingual documentation.

✅ Tested and open

Hundreds of tests (Vitest), CI on every change and the MIT licence.

Quick start

Choose how to use it

Packages are distributed through GitHub releases.

  1. Plain HTML (Django, PHP...): load kelsoncm-tiptap.bundle.js from the web component release and use <kelsoncm-tiptap name="field"> in the form.
  2. With a bundler: install the @kelsoncm/tiptap-core release tarball and call createEditorUI(element, options).
  3. Angular: use the <app-editor> of tiptap-ng with formControlName or ngModel.
  4. Moodle: install the editor_tiptap plugin and choose the toolbar, features and plugins in the administration.

Step by step, options and commands in the getting started guide (Portuguese).
